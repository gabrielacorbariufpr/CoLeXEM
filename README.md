# CoLeXEM — Tela de apresentação

Esta versão apresenta somente a página institucional inicial do CoLeXEM.

## Conteúdo da página

- definição do CoLeXEM;
- objetivo do método;
- composição do método;
- questionário destinado ao aprendiz;
- diretrizes destinadas ao professor;
- elementos avaliados;
- explicação do processo de aplicação em quatro etapas.

## Como abrir

Extraia os arquivos e abra `index.html` em um navegador.

## Publicação no GitHub Pages

Envie `index.html`, `styles.css` e `script.js` para a raiz do repositório e ative o GitHub Pages nas configurações.
